快速上手

  1. 登录：使用已注册的账号，或通过 Windows 集成身份验证直接进入。
  2. 导入数据：点击「上传」按钮，或把 .xlsx / .csv 文件直接拖到页面上。中文 Excel 导出的 GBK 编码 CSV 也能自动识别。
  3. 编辑数据：直接在单元格中输入；新增行、批量编辑、删除选中行都由工具栏完成。完整的键盘操作见下方速查表。
  4. 保存：点击「保存」写回数据库，保存时会自动执行已配置的校验规则。
  5. 查看看板：进入「数据看板」，选择任意表格查看汇总图表。

功能说明

全局搜索

工具栏右侧的搜索框会在所有列中查找，命中内容以蓝色底纹高亮，并实时显示命中行数。搜索不影响原始数据，只改变显示范围。

快捷键 Ctrl + F 可快速聚焦搜索框；点搜索框右侧的 ✕ 清除。

查找替换

编辑器提供查找替换，可在全部数据中查找并替换内容。替换前建议先用搜索确认命中范围，避免误替换。

填充柄

选中单元格后，拖动右下角的填充柄，可把内容快速填充到相邻单元格，适合批量补序号或复制内容。

合并单元格

Excel 文件里的合并区域在导入时会原样记录，网页中按合并效果展示，导出时同样保留。

计算列

输入以 = 开头的公式即可创建计算列（如单价 × 数量），支持四则运算与单元格引用，保存后自动算出结果，适合维护派生指标。

分页

通过工具栏「每页」下拉选择 50 / 100 / 500 或「全部」。默认值可在「设置 → 偏好设置」中调整。

数据量较大时建议分页，能显著减少浏览器渲染压力。

列显示与列宽

工具栏「列」按钮可勾选要显示的列，旁边的输入框可指定列宽（60–600 px，留空表示自动）。

隐藏列只影响显示，导出与保存时数据不受影响。

选中行统计

勾选任意行后，表格下方会出现统计条，对全部为数字的列给出求和（Σ）与平均值（x̄）。

含非数字内容的列不会参与统计，避免把日期、编号算进去。

条件格式（颜色规则）

「设置 → 条件格式规则」可为数值列配置区间颜色。选择应用列后添加规则，填写最小值、最大值与颜色。

最大值留空表示「该值以上」。所有设过规则的列都会同时着色，不只是当前选中的列。

数据校验规则

「设置 → 数据校验规则」可按列设置是否必填、数据类型（数字等）、最小值 / 最大值，还支持引用其它表格的列做合法值校验。

保存数据时会逐行检查，校验不通过的行会给出具体行号与原因，整批数据不会写入。

透视汇总

选择维度列与数值列、指定聚合方式，即可生成跨行分组汇总，并支持导出——不用写公式就能得到「按地区 / 按月份」这类统计结果。

导出

导出菜单提供四种方式：导出 Excel、导出 CSV、导出当前视图 CSV（只含搜索与排序后的结果、且遵循当前列显示设置）以及下载导入模板。

撤销与重做

单元格改动会记录历史，支持最多 50 步。

快捷键：Ctrl + Z 撤销，Ctrl + Y 重做。状态栏会显示剩余可撤销 / 可重做步数。

表格管理与回收站

「表格管理」页以卡片形式列出全部表格，可打开编辑、重命名、复制、单独导出或删除。

删除不会立刻清数据：表格会进入回收站并保留 30 天，期间可随时恢复；确认不再需要时可在回收站里彻底删除，数据与关联的审计、校验规则将一并清除。

键盘与快捷键

单元格操作只在可编辑单元格上生效，不影响页面其它输入框；越过页边界时会自动翻页并落在目标行。

单元格导航与编辑（表格编辑器内）

Enter / Shift + Enter下移 / 上移一格
Tab / Shift + Tab右移 / 左移一格（到行尾自动换行，与 Excel 一致）
↑ / ↓上移 / 下移一格
← / →光标先在格内移动，到首 / 尾才跳到相邻单元格
Shift + 方向键从当前格扩展选区（Excel 的选区手感）
Ctrl + Home跳到第一个单元格
Ctrl + End跳到最后一个单元格
Esc取消编辑 / 关闭当前弹窗

全局快捷键

Ctrl + F聚焦全表搜索
Ctrl + Z撤销
Ctrl + Y重做
Ctrl + K打开命令面板（跨页面快速跳转 / 执行操作）

常见问题

上传后提示「文件解析失败」怎么办？

目前支持 .xlsx 与 .csv 两种格式（把其它文件直接改后缀是不行的），且要求第一行为表头、至少有一行数据。CSV 需为 UTF-8 或 GBK 编码，中文 Excel 导出的 CSV 通常可以直接使用。

保存后为什么提示某些行不合法？

说明这些行违反了「数据校验规则」。提示中会带行号与具体原因，修正后再次保存即可。校验不通过时整批数据都不会写入，不会出现「改了一半」的情况。

关闭浏览器后数据会丢吗？

不会。数据保存在服务器数据库中，只有点击「保存」后才会写回。未保存的编辑在关闭页面后会丢失。

搜索后保存，会把搜索之外的行删掉吗？

不会。保存提交的始终是完整数据，搜索只是显示层的筛选。但删除选中行时需要注意：删除只作用于被勾选的行。

误删了整张表格还能找回来吗？

可以。删除的表格会进入回收站保留 30 天，在「回收站」页点「恢复」即可原样找回（数据、审计历史、校验规则都还在）。超过 30 天会被系统自动彻底清除。
